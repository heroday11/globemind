# V0.10 Assistant 模块化审计（第三批）

日期：2026-07-11

## 基线与结果

原 `views/DataAssistant.vue` 为 5240 行，并通过 `components/AssistantDrawer.vue -> views/DataAssistant.vue` 形成 shared 到路由页的反向依赖。主组件另有 7824 行 scoped CSS 和三个私有子组件。

本批完成后：

- 路由兼容壳 `views/DataAssistant.vue` 为 24 行，不增加 DOM 包装，继续保留原 `embedded`、`pageSkill` 和 `page-action` 契约。
- 实际体验组件迁入 `features/assistant/AssistantExperience.vue`，由 5240 行降至 4933 行。
- `AssistantDrawer.vue` 与 DataAssistant 私有子目录全部迁入 assistant feature。
- 原 shared Drawer 文件删除，7 个调用页面统一通过 `@/features/assistant/index.js` 导入。
- 主体验和两个数据面板不再直接调用 `fetch`；所有请求集中到 `api.js`。

## Feature 边界

- `api.js`：拥有 schedule、workspace/file、session/message、KB、sites/members 和流式助手端点，统一 auth、URL 编码、响应解析和 HTTP 错误。
- `dto.js`：统一 provider、workspace、session、message 和 briefing schedule 的前端 DTO。
- `state.js`：集中 SSE 分帧、请求取消作用域、Abort 判定、JSON 容错、时间/文件夹格式化和页面动作查询提取。
- `AssistantExperience.vue`：保留 Vue 状态、交互编排、报告生成和流式事件应用。
- `AssistantDrawer.vue`：保留抽屉布局、浮窗/停靠、尺寸持久化和兼容 props/emits。
- `components/`：feature 私有的知识库、成员/站点、Markdown 与样式。
- `index.js`：页面与 shared 调用的唯一公开入口。

## 残余职责

- `AssistantExperience.vue` 仍接近 5000 行，同时承担聊天、报告、简报、收藏、工作区和上下文组装；下一批应按 `chat`、`reports`、`briefings`、`workspace` 提取 composable。
- 7824 行样式仍为单文件，需先建立桌面/嵌入式视觉回归截图后再按子视图拆分。
- SSE 事件如何更新 tool calls、sources 和报告进度仍在组件内，后续适合抽成 reducer，并用事件序列测试固定。
- 会话和消息的 localStorage 缓存仍由组件管理，后续应迁入独立 repository，避免缓存键散落。
- 当前没有 Vue 组件测试框架；本批用 Node 契约测试固定 API、DTO、取消、公共入口和 Drawer/路由兼容表面。
- 完整 `npm run lint` 当前剩余 29 个本批范围外错误，较第二批的 46 个减少 17 个；assistant feature、路由兼容壳和契约测试的聚焦 ESLint 已通过。
- 隔离生产构建通过，路由壳保持独立小 chunk，助手主体由 Drawer chunk 复用；仍有两个绝对路径资源和 `vendor-echarts` 大包的既有构建警告。
