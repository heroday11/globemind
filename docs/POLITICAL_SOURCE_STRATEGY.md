# Political Source Strategy

日期：2026-06-21

## 修订后的目标

构建一套能够较稳定、较全面反映全球政治动态的高质量一手信息源体系，覆盖：

- 官方机构
- 国际组织
- 通讯社
- 国家级主流媒体
- 区域重点媒体

用于持续追踪三类信号：

1. `事件`
   谁做了什么，何时发生，涉及哪些国家与组织。
2. `立场`
   政府、国际组织、国家媒体、外交体系的正式表态。
3. `叙事`
   各国主流媒体如何 framing 同一事件，是否出现跨地区叙事分化。

## 为什么不再用“官方新闻媒体”这个表述

原目标里“官方”“新闻媒体”“一手消息源”混在一起，会造成选源时标准冲突：

- 官方源能代表立场，但不能独立代表完整现实。
- 主流媒体能代表报道与 framing，但不等于官方表态。
- 通讯社更强在时效性与事件基线。

所以现在改为：`多层级高质量一手信息源体系`。

## 分层模型

### Layer 1: Official Direct

定义：

- 政府官网
- 外交部/国防部/政府新闻办公室
- 国际组织

作用：

- 跟踪正式声明
- 跟踪政策动作
- 跟踪外交口径变化

### Layer 2: Wire Fast

定义：

- 国际通讯社
- 国家通讯社

作用：

- 提供高时效事件流
- 为多地区新闻建立共同事件基线

### Layer 3: Media Narrative

定义：

- 全球主流媒体
- 国家级主流媒体
- 公共广播
- 区域重点媒体

作用：

- 观察各国叙事差异
- 观察重点地区议程设置
- 观察事件在不同媒体生态中的结构性偏差

## 纳入标准

- 站点持续生产新闻或官方公开信息
- 有稳定的栏目页、列表页、新闻页或声明页
- 在政治、外交、国际事务、国家治理上有持续输出
- 域名可信、归属明确
- 能提供较稳定的时间戳和正文

## 排除标准

- 非新闻站
- 论坛、博客平台、词典、百科、企业站、电商、旅游、娱乐、体育站
- 只偶尔发布与公共事务无关信息的站点
- 结构极不稳定、正文难抽取、长期噪声远大于价值的站点

## 分布原则

目标不是“平均分布”，而是“自然且任务相关的分布”。

这意味着：

- 亚洲、中东本来应略高，因为涉华与地缘政治密度更高
- 欧洲、北美必须有足够的高质量基线媒体
- 拉美与非洲不能缺席，否则会失真
- 官方层不能只集中在西方政府

## 当前维护原则

1. 主新闻骨干库优先维护 `P0/P1`
2. 官方层单独维护，不与一般媒体混淆
3. `P2` 用于补国家、语种、地区缺口
4. 任何新增站点都应先判断属于哪个层，而不是只判断“要不要抓”
