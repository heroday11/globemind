# L2 质量审查报告 2026-06-17

## 结论

本轮 L2 重构后，**展示层质量已从“不可用/过挤”提升到“可用且有明显分析价值”**，但**分析层质量还没有到最终形态**。

核心判断：

- `display story` 层已经基本压住了“超级大图”和“单日爆炸拥挤”。
- `macro story` 层仍然存在明显的**过度合并**，尤其是高热长期冲突主题。
- `chapter` 内部仍有一部分故事出现**类型混杂**，即同一章节同时混入军事 / 外交 / 贸易冲突，说明目前章节切分仍偏“实体连续性优先”，还不够“事件阶段纯度优先”。
- 当前 `story_edges` 已经高度线性化，**可读性提升很大**，但**结构表达力不足**，对后续“分析层 / 世界模型层”来说还缺少分叉、并行支线、因果参考关系等结构。

因此，L2 **仍有继续优化的空间和必要**，但优化重点不再是“继续压尺寸”，而是：

1. 提高章节内部的语义纯度。
2. 把宏观关联从“过度合并”改成“关系图/参考图”。
3. 给分析层保留分叉与支线，而不是只保留线性主链。

- 展示故事数：`160`

- 纳入 L2 的 L1 节点数：`765`
- L2 边数：`605`
- 平均每个展示故事节点数：`4.78`
- 中位展示故事节点数：`4`
- P90 展示故事节点数：`9`
- 最大展示故事节点数：`12`
- 单日最大节点密度：`4`

故事大小分布：

- `2` 节点：`44`
- `3` 节点：`25`
- `4` 节点：`32`
- `5` 节点：`12`
- `6` 节点：`10`
- `7` 节点：`10`
- `8` 节点：`6`
- `9` 节点：`5`
- `11` 节点：`1`
- `12` 节点：`15`

这说明展示层的“尺寸控制”已经明显成功。当前最大 story 被限制在 `12` 个节点，和改造前那种几十节点甚至更大的头部图相比，已经下降到了可展示区间。

## 结构性发现

### 1. 展示层已经稳了

当前 `display story` 的节点规模、时间密度都已经受到硬约束：

- 最大 story 固定在 `12` 节点。
- 单日最多 `4` 个节点。
- 平均 story 只有 `4.78` 个节点。

这意味着当前前端展示已经不会再出现“某一天堆几十个节点”的严重拥挤问题。

### 2. 宏观层仍然明显过大

宏观故事组分布里，头部集中度非常高：

- 最大 macro group：`81` 个 chapter
- 该组占全部展示 story 的比例：`50.63%`
- 前 3 个 macro group 合计占比：`68.75%`

这说明当前 `macro story` 仍然容易把高热长期议题合成一个过大的上层块。

典型例子：

- `macro_story_id = 1570781470`
- 覆盖 `81` 个 chapter
- 时间跨度：`2026-01-06` 到 `2026-05-20`
- 实质上把美伊、以伊、相关军事/外交/贸易冲突阶段放进了同一个宏观组

这对“高层态势理解”有一定价值，但对于后续世界模型和 agent 分析来说，**这个粒度仍然过粗**。

### 3. 章节内部纯度仍有不足

按 story 内事件类型主导占比统计：

- 平均 dominant type share：`0.7872`
- 中位 dominant type share：`0.8333`
- 主导类型占比 `< 0.8` 的 story：`76 / 160`
- 主导类型占比 `< 0.7` 的 story：`59 / 160`

这说明将近一半的章节，内部仍然不是高纯度单阶段事件链。

典型问题 story：

- `695593370` `US对Iran的贸易冲突事件`
  - 主导类型占比仅 `0.417`
  - 内部同时混入 `military / diplomacy / trade_conflict`
- `504691166` `US对Ukraine的援助救灾事件`
  - 主导类型占比仅 `0.400`
  - 内部混入 `diplomacy / aid_disaster / military`
- `299741830` `Trump对Iran的军事事件`
  - 主导类型占比仅 `0.417`

这类 story 在展示上虽然不大，但在语义上并不够“单阶段一致”。

### 4. 当前 L2 过于线性

当前图结构的度分布结果：

- 最大出度：`1`
- 最大入度：`1`
- 出度 > 1 的节点数：`0`
- 入度 > 1 的节点数：`0`

这说明当前 `story_edges` 实际上已经不是“演化图”，而是“线性章节链”。

优点：

- 可读性强。
- 展示稳定。

缺点：

- 无法表达并行支线。
- 无法表达“同一阶段下的多分支响应”。
- 无法支持更高阶的结构分析，如关键分叉点、分支收敛点、分叉后风险传导。

因此，当前版本更像是**展示友好的主链层**，还不是完整的分析图层。

### 5. 时间精度问题仍未真正解决

当前 `story_trees.meta.time_precision` 全部为：

- `date_midpoint`

这说明虽然前端和后端都已经支持更细的 `display_time` 逻辑，但当前底层数据里，L2 实际仍然主要在使用“天级别时间 + 中点近似”。

也就是说：

- 展示拥挤问题已经被“章节化 + 同日内约束”缓解了。
- 但时间排序本身仍未真正进入小时级。

这会限制后续对“先后顺序”“即时回应”“同日并发事件”的分析能力。

## 抽样审查

### 样本 A：`1244977487` `Russia对Ukraine的军事事件 第1阶段`

人工阅读该 story 的样本标题：

- 俄方导弹/无人机打击
- 乌克兰能源设施受袭
- 安理会紧急讨论
- 连续多日攻击

判断：

- 该 story 内部高度一致。
- 主题连续。
- 事件类型稳定为 `military`。
- 这是当前 L2 中的**优质章节样本**。

说明 L2 现在已经具备把“高频同类连续事件”切成有价值演化段的能力。

### 样本 B：`695593370` `US对Iran的贸易冲突事件`

人工阅读该 story 的样本标题：

- 特朗普谈核武/伊朗
- 霍尔木兹海峡封锁
- Rubio 发言
- 特朗普评估伊朗新提案
- 和谈僵局
- 石油出口受阻

判断：

- 虽然整体围绕同一地缘主题，但内部明显混入：
  - 军事威慑
  - 外交谈判
  - 经济/封锁/油运冲突
- 它更像“同一危机窗口的综合态势片段”，而不是单一类型章节。

这类章节有一定分析价值，但如果直接作为“一个阶段”输入分析层，会让状态转移含义变得模糊。

### 样本 C：`300971442` `Iran对US的外交事件 第6阶段`

人工阅读该 story 的样本标题：

- 伊朗排除会谈
- 新提案/对案
- 谈判僵局
- 霍尔木兹海峡议题
- 美国轰炸威胁

判断：

- 前半段较像外交谈判章节。
- 后半段开始混入军事威慑与贸易/航道风险。
- 比样本 B 更顺，但仍未达到“纯外交阶段”的严格标准。

### 样本 D：`504691166` `US对Ukraine的援助救灾事件`

人工阅读该 story 的样本标题：

- Rubio 讨论乌克兰问题
- Pentagon 支持基辅
- 美国继续情报/武器援助
- Rubio 批评 Zelensky
- 美国武器前景转弱

判断：

- 内部主题相关，但类型混杂较重。
- 更准确的标签应接近“美乌支持/博弈章节”，而不是单纯 `aid_disaster`。

这暴露了当前 L2 的另一个问题：

- `story` 标题和 `dominant_type` 仍然过度依赖单个主导标签。
- 对混合型章节的命名和归类不够稳。

## 质量判断

### 已达到的水准

当前 L2 已经达到：

- 可用于前端展示。
- 可用于中层事件演化浏览。
- 可用于给分析层提供“主链式阶段块”。

相较之前，最大的质量提升在于：

- 解决了大图拥挤问题。
- 解决了单日极度密集问题。
- 解决了 story id 不稳定问题。
- 把 L2 从“失控的大连通图”拉回到了“可读的阶段链”。

### 还没达到的水准

当前 L2 还没有达到：

- 高纯度的阶段级 story。
- 能表达并行支线和收敛点的分析图。
- 足够稳定的 macro 层主题边界。
- 足够高的时间精度。

## 还有无改进空间和必要

结论：**有，而且有必要，但不需要再回到“大图思路”。**

后续改进应集中在以下方向。

### P1：章节内部纯度继续提高

必要性：高。

建议：

- 在 chapter 切分中增加“类型纯度约束”。
- 当同一章节内 `military / diplomacy / trade_conflict` 混杂明显时，优先再切一刀。
- 对高热 pair（如 `US-Iran`）使用更严格的章节切分阈值。

目标：

- 把 dominant type share 平均值从 `0.787` 提升到 `0.85+`
- 把 `<0.8` 的章节数明显压低

### P1：宏观层从“合并”改成“关系”

必要性：很高。

当前最大 macro 占了 `50.63%` 的展示 story，这说明它更适合作为“上层关联图”，而不是“一个大故事”。

建议：

- macro 层不要继续做强连通合并。
- 改成：
  - chapter 是主对象
  - macro relation 是 chapter 之间的 `related / response / shared_entity_context / same_crisis_window`
- 上层可以是图，不必是单一 story 容器。

### P2：恢复受控分叉，而不是完全线性

必要性：中高。

当前完全线性的好处是清晰，但对分析层不够。

建议：

- 主链保持线性 backbone。
- 额外引入少量 `reference_edges` / `parallel_edges`，单独存入 meta 或单独表。
- 展示时默认只画 backbone；分析时可读参考边。

### P2：标题和类型标签改成“阶段语义标签”

必要性：中。

当前很多标题还是 `X对Y的军事事件` 这种模板，无法准确反映“谈判僵局”“海峡封锁危机”“援助收缩阶段”这类阶段语义。

建议：

- 标题生成更多参考 cluster headline。
- 对混合型阶段，不强行贴单一 event_type，而是给二级阶段标签。

### P3：补小时级时间

必要性：中。

如果底层新闻时间本身有小时级，就应尽量回写到 L1/L2；如果没有，也应至少保留：

- 同日内顺序估计
- 先报道 / 后回应 / 后升级 的相对序

这会显著提升世界模型和 agent 分析层的可用性。

## 最终判断

L2 当前版本已经值得继续作为**正式展示管线**使用，也值得作为**分析层的中间输入**使用。

但如果目标是后续接世界模型和 agent 做高质量预测分析，那么当前 L2 仍建议继续迭代，重点不是“再缩图”，而是：

1. 提高 chapter 内部纯度。
2. 让 macro 层从强合并变成关系层。
3. 给分析层恢复少量可控分叉结构。

一句话概括：

**当前 L2 已经从“图太大不可用”进化到“主链可用、宏观仍粗、分析还可继续打磨”的阶段。**
