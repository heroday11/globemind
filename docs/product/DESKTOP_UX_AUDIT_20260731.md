# GlobeMind 桌面端体验审计（2026-07-31）

## 范围

- 视口：1440 × 1000，仅桌面端。
- 流程：首页 → 数据搜索 → 未登录数据助手 → 未登录报告中心 → 个人中心登录跳转 → 新手指南。
- 证据：`analysis_output/desktop-ux-audit-20260731/` 下的本轮 Chromium 截图。
- 本轮不评价移动端，也不声称完成完整 WCAG 合规验证。

## 流程健康度

1. 首页：一般。功能卡片可理解，但整体对比度偏低，装饰性蓝色占比过高，卡片正文和背景图片互相竞争。
2. 数据搜索：差。首次进入时首屏出现大面积空白，用户无法判断是在加载、出错还是没有内容。
3. 未登录数据助手：一般。登录门槛存在，但页面空白过多，登录收益、注册入口和权限边界不够完整。
4. 未登录报告中心：差。页面把未登录状态表现成“暂无报告”，并仍提供“打开数据助手”，容易让用户误判为数据为空。
5. 个人中心登录跳转：一般。能正确跳转登录，但登录页与主站的字体、背景和卡片语言明显割裂。
6. 新手指南：一般。文字层次清楚，但教程遮住整个产品，没有指向真实控件，也不会随步骤进入对应页面。

## 主要视觉问题

### P0：影响理解和完成任务

- 数据搜索首屏缺少明确加载骨架或错误状态，截图 `02-search.png` 为近乎全空白页面。
- “未登录”和“没有数据”使用了同一种空状态；报告中心没有先解释权限要求。
- 教程与真实界面脱节，用户读完说明后仍需自己寻找功能入口。

### P1：视觉系统不一致

- 首页使用高亮玻璃拟态、报告中心使用白色档案卡、登录页使用大面积纯蓝渐变、故事图谱与舆情页又各自维护独立视觉语言。
- 蓝色使用层级过多：背景、边框、按钮、图标和插画同时偏蓝，缺少中性色和重点色分工。
- 标题体系混用中文黑体、英文全大写衬线/等宽感字样，字号、字重和字间距没有统一节奏。
- 卡片圆角、阴影、描边和留白尺度在页面间变化较大，导致产品像多个独立演示页面拼接。

### P2：视觉和无障碍风险

- 浅蓝背景上的灰蓝正文、卡片中的辅助文字对比度偏低。
- 顶栏问号按钮只有图标，首次使用者很难理解其含义。
- 空状态和登录门槛大量依赖居中大留白，视觉焦点弱且在高分辨率屏幕上更明显。
- 截图不能确认完整键盘路径、屏幕阅读器名称和缩放重排，需要单独做交互测试。

## 本轮修复边界

- 增加全局、持续可见的访客模式说明。
- 报告中心明确区分“未登录”和“暂无报告”。
- 把新手指南改成跨页面的聚焦式教程：自动导航、框选真实控件、说明当前可做什么。
- 在个人中心提供可重复观看入口。
- 全站视觉重构留到后续独立设计迭代；移动端不纳入本轮验收。
