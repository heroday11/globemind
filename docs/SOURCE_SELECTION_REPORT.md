# Source Selection Report

日期：2026-06-21

## 目的

把最初那份混合站点长名单，整理成适合三年历史新闻抓取与分析的可执行网站池。

## 输出文件

- [recommended_sources_catalog.csv](/root/data/globemind/data/source_curation/recommended_sources_catalog.csv)
  主分类表，字段包括：
  - `priority_tier`
  - `quality_tier`
  - `source_type`
  - `action`

## 分类口径

- `P0`
  第一轮直接抓取。以高质量国际主流媒体、公共广播、核心国家级媒体、官方国际组织源为主。
- `P1`
  第二轮补充抓取。全国性主流媒体与重要经济政策媒体。
- `P2`
  条件抓取。区域媒体、国家媒体、多语种补充源、部分官方机构。
- `P3`
  不进新闻主库，只做分析参考。主要是智库、研究机构、政策评论源。
- `Drop`
  直接剔除。企业站、论坛、词典、体育娱乐、旅游、电商、博客平台等。

## 质量口径

- `A`
  权威、稳定、正文质量高、历史价值高。
- `B`
  有抓取价值，但稳定性、结构化程度或国际影响力略弱于 `A`。
- `C`
  有条件保留。通常用于补区域、补语种、补国家视角。
- `D`
  不适合进入新闻主库。

## 类型口径

- `official_io`
  国际组织官方源
- `official_government`
  政府官网新闻源
- `state_media`
  国家通讯社或国家媒体
- `public_broadcaster`
  公共广播机构
- `wire_service`
  通讯社
- `global_major_media`
  全球主流媒体
- `national_major_media`
  各国主流全国性媒体
- `regional_major_media`
  区域重点媒体
- `business_media`
  商业财经媒体
- `think_tank_context`
  智库与研究机构
- `noise`
  应排除的非新闻站

## 当前结论

这次迭代不是只保留一个很窄的核心池，而是把名单拆成了五层：

1. `P0 A`
   直接作为历史正文主库的第一批目标源。
2. `P1 A/B`
   在第一批跑通后继续扩展覆盖面。
3. `P2 B/C`
   只在明确需要国家、语种或地区补充时抓取。
4. `P3 C`
   只做解释和分析对照，不混入新闻主库。
5. `Drop D`
   明确排除。

## 抓取建议

第一阶段：

- `P0` 全抓
- 优先顺序：
  - 官方与国际组织
  - 全球主流媒体
  - 亚洲与中东重点媒体

第二阶段：

- 补 `P1`
- 重点补：
  - 印度
  - 巴基斯坦
  - 东南亚
  - 台湾
  - 土耳其

第三阶段：

- 只按专题补 `P2`
- 优先用于：
  - 小语种
  - 国家视角对照
  - 官方或国家媒体 framing

## 注意

- 表中少数站点当前 URL 不是最佳抓取入口，但域名本身仍然有价值。
- 对这类站点，`notes` 字段已经明确标出应当替换成更合适的栏目页或新闻页。
